# Exploit Shortlist (Index)

> Check this table first when entering a site; if a pattern matches, open “see xxx.md” for details (short files can be opened whole; for long files, open the named section first and continue if needed). Do not read the entire knowledge base at every site. Adding/updating this table is governed only by the on-disk `hunt-iter.md` (rules directory; it only strengthens requirements and does not restrict them). Before editing this table, read that file's current version; do not use an old conversation copy.
> **This table is not the site's complete checklist.** After a few opening probes, return immediately to `dig-scope` §4: understand the target, extract keys from JS, queue responses. With no account, test the four high-difference surfaces; with an account, start with object graph / ID changes (§4.2.3). Still run the full type matrix on each site: authorization bypass / unauthenticated sensitive reads / logic / credentials / weak passwords / auth sessions / upload chain… Test whatever is present. Injection / SSRF / XSS / RCE are “must test when there is a meaningful difference surface; don't leave a multi-day gap,” **not** the only four categories to test, and not a license to spray `'` at every path. Test techniques absent from the table too.
